# Web GUI Artwork

The board and power-plant images in this directory were copied from the local
art archive supplied for the Web GUI implementation:

`Boardgame-assets/Power Grid/Power Grid/assets/data/pics/game`

The source plant filenames are sequence identifiers rather than plant prices.
The Web GUI copies the first 42 card faces in deck order and renames them to the
printed plant price (`3.png` through `50.png`, with the normal gaps). `kw-85.png`
is used for the Step 3 card.

The repository does not make a new licensing claim for these supplied assets.
Confirm distribution rights before publishing a public build.
