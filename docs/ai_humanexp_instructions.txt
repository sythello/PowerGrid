【第一回合拍卖阶段】
首先定义”竞对“断言：假设自己买下待评估电厂后，剩余尚可购厂的对手有k人。“竞对x1, x2, ..., xn”指电厂x1, x2, ..., xn均在剩余当前市场或未来市场的最小k个之内，且n <= k；自己买下的电厂不计入竞对。直观理解即“我这轮买电厂之后，其他玩家有可能通过拍卖拿到全部x1, x2, ..., xn这些电厂”。例如3人局：
当前市场3, 4, 5, 6；未来市场7, 8, 9, 10。则如果第一顺位玩家拍卖4，“竞对5, 8“成立，另两位玩家可能买到5和8；”竞对9“不成立，不可能买到9

起拍操作：
- 当自己起拍时，先排除最低合法价格超过心理最高出价的电厂，再按照上述偏好顺序选择最高的；如果没有符合心理上限的电厂，则选择最低合法起拍价的电厂（包括1元特价）。无论有无对手均如此。初始出价总是出最低价。

竞拍操作：
- 无论是谁起拍，只要拍卖过程轮到自己，按以下方式决策：
-- 如果超出心理最高出价，pass
-- 如果已经达到心理最高出价-2到-1，需要计算下一个出现的电厂优先级
--- 如果牌堆顶是插头（小号电厂），根据未见的插头牌计算当前拍卖结束后下一个出现的可拍电厂的概率分布（牌堆顶或未来市场最小号）。如果至少50%概率偏好高于当前电厂，则pass。否则，继续加价。
--- 如果牌堆顶是插座（大号电厂），则下一个出现的可拍电厂一定是未来市场最小号。如果其偏好高于当前电厂，则pass。否则，继续加价。
-- 如果当前出价在心理最高出价-3或以下，继续出价

【后续回合拍卖阶段】
定义对于资源购买价格估算方式：
- 默认先按照当前市场的价格进行估算
- 每有一位顺位比自己靠后（即买资源时顺位靠前）的玩家，有对应资源类型的电厂（包括混合电厂），按他们会把对应类型资源买到1.5x发电所需（向上取整），按之后的价格估算
- 此外，在拍卖阶段，如果有对应资源类型的竞对电厂，按0.5x发电所需估算额外会被购买的量（向上取整）
- 上述估算中，混合电厂按较便宜的可用煤、石油组合分摊总需求，不向煤和石油分别计入完整需求。

定义对于城市建设价格的估算方式：
- 默认先按照当前地图的价格进行估算
- 每有一位顺位比自己靠后（即建城市时顺位靠前）的玩家，按每座城市价格+1估算

定义“终局电厂”：将游戏结束城市数计为E
- 第1座终局电厂：发电量 >= E * 1/3 - 1（向上取整）的电厂；其发电量计为P1
- 第2座终局电厂：发电量 >= (E - P1) * 1/2 - 1（向上取整）的电厂；其发电量计为P2
- 第3座终局电厂：发电量 >= (E - P1 - P2) - 1的电厂
- 按成为终局电厂的先后顺序认定；P1、P2保留历史值，不因后买的电厂发电量更高，或原厂被替换、丢弃而重排或清除。已持有的旧厂一旦满足更新后的门槛，也立即认定为终局电厂。

定义“最差电厂”及替换对象：购买前累计认定不足3座终局电厂时，取编号最低的电厂，不比较发电量；已有3座后，替换发电量最低的电厂，同发电量时编号最低。估算和实际弃厂采用同一规则。

定义电厂“性价比”：该电厂发电量 / 对于一次发电的估算资源购买价格

以下起拍、竞拍中，若购买前已累计认定3座终局电厂，则仅按“候选发电量严格高于自己当前最低发电量，且C_i >= P+1”筛选，包括1元特价；不再使用原第3座终局门槛、+2发电量、1.5倍编号或P/C缺口条件，也不再接受C_i == P。满足者均按下文“C_i >= P+1且是终局电厂”处理。

起拍操作按以下顺序决策：
- 估算将当前资金购买资源以供给当前所有电厂，之后全部用于建城市，能建几座城市。将建设后的城市总数（包含已有城市）计为C，当前发电厂总发电量计为P。
- 市场中如果有1元特价电厂，且自己电厂未满，或其编号 >= 自己最差电厂 * 1.5，则直接将该电厂加入“可拍”集合
- P >= C-1，则其他电厂均不加入可拍集合
- P <= C-2：
-- 查看当前市场中每个非特价电厂。如果电厂已满，首先排除发电量低于自己最差电厂发电量+2，或其编号 <= 自己最差电厂 * 1.5的候选
-- 对于其他候选电厂，估算如果底价买下之后（电厂已满则替换最差发电厂），再购买全部资源和建城市，将建设后的城市总数（包含已有城市）计为C_i（i代表电厂编号）
-- 如果C_i >= P+1，则将该电厂加入“可拍电厂”集合
-- 如果C_i >= P，且是终局电厂，则将该电厂加入“可拍电厂”集合
- 最终，如果可拍集合为空，则放弃起拍直接pass。否则，按以下顺序决定起拍电厂：
-- 1. C_i >= P+1且是终局电厂的。（存在多个的情况下，选择性价比最高的，下同）
-- 2. 1元特价电厂
-- 3. C_i >= P+1的非终局电厂
-- 4. C_i == P的终局电厂

后续竞拍操作：
-- 对于C_i >= P+1的非终局电厂，或C_i >= P的终局电厂，需要先计算满足前述条件下的额外剩余资金m；心理最高出价为电厂编号底价～底价+min(m, 3)；对于C_i >= P+1且是终局电厂的，心理最高出价为底价～底价+min(m, 10)，按范围在局内随机
-- 对于不满足上述条件的电厂（应该是对于1元特价电厂），不竞拍

【资源购买阶段】
- 尝试枚举买资源供给的发电厂组合，并估算建造城市数量，对应获得的收入，选择 收入 - 资源开销 最高的方案。
- 预留上述最优方案的建城费用后，如果仍有结余资金，看 全场资源消耗量 - 每回合资源补充量 = 资源缺口 最大的资源，尽可能额外购买该类资源。如果该类资源购买资金不足或无存储空间，再购买缺口次大的资源，以此类推。不额外购买没有资源缺口的资源

【城市建设阶段】
- 先计算每位对手相邻最便宜的3座城市。他们的价格前三名分别视为价格-2，-1，-1。在此adjuster下，总是优先购买最便宜的城市。
- 建造城市数量不超过自己的发电量，除非自己是第一顺位（最后一个建城市）且下轮仍然是第一顺位，则尽可能多建城市

【发电阶段】
- 枚举可发电的电厂组合，选择尽可能多发电的方案
